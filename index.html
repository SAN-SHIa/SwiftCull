Is SwiftCull really free?

Yes. SwiftCull is free to download and use, with source code available under the MIT License. Explore the code, report an issue, or contribute an improvement. Third-party assets and fonts retain their own licenses.

Which systems and file formats are supported?

SwiftCull requires macOS 14.0 (Sonoma) or later. Scanning currently supports JPEG, HEIC, HEIF, TIFF, and RAW formats including NEF, CR2, ARW, DNG, and RAF. Video formats include MOV, MP4, and AVI.

RAW decoding and video playback depend on macOS support for the specific camera format and codec. PNG and CR3 are not currently included in scanning.

Will cropping change my original photos?

Cropping is non-destructive: it leaves the original image content unchanged. Update a version or create a virtual copy; previews, copying, and export use the selected version. Frames and watermarks are also exported to new files.

Ratings are stored per photo folder. Finder tags are written to the metadata of associated files.

How do I install it? What if macOS blocks it?

Download SwiftCull.dmg from GitHub Releases, open it, and drag SwiftCull into your Applications folder.

A build that is not notarized by Apple may be blocked by macOS security checks. After confirming the file came from this project’s Releases page, check the relevant prompt in System Settings → Privacy & Security.

How can I report an issue or contribute?

Suggestions and bug reports are welcome on GitHub Issues. Include your macOS version, app version, file format, and reproduction steps. See the project README for source builds and contribution guidance.
